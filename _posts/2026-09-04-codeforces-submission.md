# Codeforces

As part of our task, we wanted to solve the problems from [A2OJ](https://a2oj.online/) ladders. In the A2OJ Online Ladder, enter your Codeforces handle to track your progress. Click on the problem to solve and you will be redirected to Codeforces.

## Steps to make a submission

1. Read the problem statement
2. Write the code. You have to get the input and print the output in the expected format. Note that, this is not the function completion problems

You have a couple of ways to make a submission

1. From Submit Tab
* After reading the problem, note down the Problem Statement Code from the URL. For example, if the URL says **https://codeforces.com/problemset/problem/69/A**, then the Problem Code is 69A.
* Then navigate to the Submit Tab.
* Enter the Problem Code
* Choose the language
* Paste your code on the Source code or upload your source code file below
* Click on Submit. You will be redirected to the Submissions page.
* The verdict says the status of your submission

2. From Submit section in the Problem Statement page
* Choose the language
* Upload your source code file (your actual submission code)
* Click on Submit. You will be redirected to the Submissions page
* The verdict says the status of your submission

In case of Compilation Error or Wrong Answer or TLE or any other kind of errors, fix the code and resubmit. Also, note that, you have to get the input and format the output in the expected format.
